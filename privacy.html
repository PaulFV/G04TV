Privacy Policy

G04TV · Last updated: 12 September 2026

Short version

G04TV is a client-side web app for playing IPTV sources that the user enters. G04TV has no user account, sign-in, advertising, analytics, tracking or operator backend. The app stores its working data locally in the browser.

Operator and privacy contact

G04TV is published as the open-source project PaulFV/G04TV. For privacy questions or deletion requests, contact the project through the G04TV GitHub Issues page.

Before submitting the Android app to Google Play, the publisher should verify that the Play Console developer identity, legal operator details and privacy contact are complete and consistent with this policy.

Connections outside the app

  • User-selected providers: playlist and stream URLs are requested from the sources entered by the user. Those providers can see the request IP address and request details.
  • Channel logos: image URLs from a playlist are loaded from the listed host.
  • Optional proxy: if the user configures and enables one, the full playlist or stream URL, including credentials embedded in it, is sent to that proxy. A proxy used for streams can also observe which stream is played and for how long.
  • Playback libraries: if they are not supplied locally, HLS.js or mpegts.js is loaded from cdnjs or jsDelivr when the selected format requires it.
  • GitHub Pages: when this page or the app is hosted there, GitHub may process technical request data under its own policies.

Cookies, advertising and profiling

G04TV does not set cookies and does not use advertising, analytics, profiling, a user ID or an account system.

Retention and deletion

The user can delete playlists, channel lists, favorites, history and settings in the app under Settings → Data on this device → Delete everything. Browser website-data controls provide an additional deletion method. Data sent to a provider or an optional proxy is subject to that recipient’s own retention policy.

Security

The public app and this policy are delivered over HTTPS when hosted on GitHub Pages. Local browser storage is protected by the browser’s origin model, but users should only enter credentials into sources and proxies they trust. No security system can be guaranteed to be completely risk-free.

Changes

Material changes to this policy will be published on this page with a new update date.

Datenschutzerklärung

G04TV · Stand: 12. September 2026

Kurzfassung

G04TV ist eine clientseitige Web-App zum Abspielen von IPTV-Quellen, die die nutzende Person selbst einträgt. G04TV hat kein Benutzerkonto, keine Anmeldung, keine Werbung, keine Analyse, kein Tracking und kein Betreiber-Backend. Die Arbeitsdaten werden lokal im Browser gespeichert.

Betreiber und Datenschutzkontakt

G04TV wird als Open-Source-Projekt PaulFV/G04TV veröffentlicht. Für Fragen zum Datenschutz oder Löschanfragen steht die Seite G04TV GitHub Issues zur Verfügung.

Vor der Einreichung der Android-App bei Google Play müssen die Identität im Play-Console-Konto, die verantwortliche rechtliche Stelle und der Datenschutzkontakt geprüft und mit dieser Erklärung abgeglichen werden.

Verbindungen nach außen

  • Vom Nutzer gewählte Anbieter: Playlist- und Stream-Adressen werden von den eingetragenen Quellen angefordert. Diese Anbieter können IP-Adresse und Abrufdaten sehen.
  • Senderlogos: Bildadressen aus einer Playlist werden vom dort genannten Host geladen.
  • Optionaler Vermittler: Wenn ein solcher selbst eingetragen und eingeschaltet wird, geht die vollständige Playlist- oder Stream-Adresse einschließlich eingebetteter Zugangsdaten an ihn. Bei Streams kann er außerdem Sender und Wiedergabedauer erkennen.
  • Abspielbibliotheken: Falls sie nicht lokal beiliegen, werden HLS.js oder mpegts.js nur bei Bedarf von cdnjs oder jsDelivr geladen.
  • GitHub Pages: Beim Hosting dort kann GitHub technische Daten eines Abrufs nach den eigenen Bedingungen verarbeiten.

Cookies, Werbung und Profile

G04TV setzt keine Cookies und nutzt keine Werbung, Analyse, Profile, Benutzer-ID oder Konten.

Speicherdauer und Löschung

Unter Einstellungen → Daten auf diesem Gerät → Alles löschen lassen sich Playlisten, Senderlisten, Favoriten, Verlauf und Einstellungen löschen. Zusätzlich können Website-Daten im Browser entfernt werden. Für Daten beim Anbieter oder einem optionalen Vermittler gelten dessen eigene Regeln.

Sicherheit

Die öffentliche App und diese Erklärung werden bei GitHub Pages über HTTPS ausgeliefert. Lokale Browserdaten sind durch das Origin-Modell des Browsers geschützt; Zugangsdaten gehören trotzdem nur in vertrauenswürdige Quellen und Vermittler. Eine vollständig risikofreie Sicherheit kann niemand garantieren.
